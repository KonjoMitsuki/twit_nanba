# 設定ペインの情報量レビュー

2026-10-27 の仕様書 §3.0 改訂に対応。改訂前の実装をデモモードで計測してから変更した。

| 条件 | 常時表示文字数 | 常設項目 | 説明・補足 |
|---|---:|---:|---:|
| PC 1440×800、折れ線を新規追加 | 814 | 13 | 20 |
| モバイル390×844、同じ折れ線、シート展開 | 787 | 13 | 20 |

計測対象は設定ペインの開いている領域全体（スクロール先も含む）。非表示要素、閉じたdetails、読み上げ専用テキスト、未選択のoptionを除外し、表示中のテキストとselectの選択値を空白除去後に数える。入力項目はchart/sourceの選択群と指標チップをそれぞれ1項目として数える。基準値は `analytics-settings-density-baseline.json`、計測コードは `tests/test_analytics_settings_density_browser.py` に記録した。

## 項目・文言の棚卸し

| フィールド・旧文言 | 配置 | 変更 |
|---|---|---|
| chart／どう見せる・表示形式のカード説明 | 基本「形式」 | アイコン選択のみ。名称はaria-labelとツールチップ |
| title／パネル名・名前の補足 | 詳細 | 「名前」。6項目以内を優先し、常時表示のパネル見出しから重複入力を除く |
| source／何を分析する・3カードの説明・行の意味・例 | 基本「データ」 | 「種類」＋3セグメント。行の意味はⓘ |
| stage／投稿からどの時点・未計測の説明 | 基本「データ」（作品のみ） | 「時点」。未計測の説明はⓘ |
| period_days／いつのデータ・日数の説明 | 基本はプリセット、任意の日数は詳細 | 「期間」「日数」。基準日と優先順位はⓘ |
| from_date / to_date／開始日・終了日・優先の補足 | 「指定」選択時のみ | 「開始」「終了」。未選択時も値は保持 |
| x／軸の設定・横軸と分類・横軸の説明 | 基本「軸」 | 「横軸」（円・箱は「分類」）。重複見出しを削除 |
| y[]／集計指標の選択・縦軸と数値・指標の説明 | 基本「軸」 | 「縦軸」または「指標」。チップ＋「追加」か単一選択 |
| bins／ビン数・区間の補足 | 基本「軸」（ヒストグラム） | 「区間数」。意味はⓘ |
| series / aggregate／系列と集計・色分けの補足・集計の補足 | 詳細 | 「系列」「集計」。選択値を短縮 |
| allocation／複数キャラの扱い・数え方・配分の説明 | 詳細 | 「配分」。意味はⓘ |
| transform / window／集計後の計算・移動平均の説明 | 詳細、点数は移動平均時のみ | 「変換」「点数」。既存集計に合わせ折れ線のみ |
| compare_previous／前の同じ長さの期間と比較・補足 | 詳細、対応形式のみ | 「前期間比較」。意味はⓘ |
| columns / show_images／表示列の選択・表の操作説明・写真の補足 | 基本「軸」（テーブル） | 「列」「写真」。一括操作はⓘ内の操作へ |
| show_images／作品カード表示 | 詳細（散布図） | 「作品カード」 |
| table_group / order / dates / multivalue | 詳細（テーブル） | 「グループ」「グループ順」「日付単位」「複数値」。説明はⓘ |
| table_sort / table_desc / table_sorts | 詳細（テーブル） | 最大5条件を維持。空なら追加ボタンのみ |
| table_collapsed_groups | プレビュー操作 | 保持。設定ペインに重複表示しない |
| filters / filter_join | 「絞り込み」（条件ありのみ初期展開） | 条件チップ。空なら追加のみ。AND/ORは必要時に表示 |
| style.color / legend / labels | 「見た目」 | 「色」「凡例」「数値」。説明を削除 |
| style.x_label / y_label / x_min / x_max / y_min / y_max | 詳細（対応形式のみ） | 「横軸名」等、8文字以下 |
| style.x_tick_interval / y_tick_interval / x_tick_unit | 詳細（対応形式のみ） | 「横軸間隔」「縦軸間隔」「単位」。入力は手動時のみ |
| style.sort | 詳細（対応形式のみ） | 「表示順」 |
| formulas／カスタム指標・使い方・関数一覧・例の説明 | 「計算式」 | 空なら追加のみ。テンプレートは追加メニュー、説明はⓘ |
| このパネルについて／各操作の長いボタン名 | ペイン末尾 | 「リセット」「複製」「削除」の1行 |
| 設定見出しの複数行要約・上部集計サマリー | 削除／プレビュー | 要約は20文字以内、集計状態はプレビューのフッターに1行 |
| 変更を破棄・未保存の変更・長いロック案内 | ヘッダー／状態 | 「破棄」「未保存」「ロック中のため編集できません」 |
| パネル追加の説明文・用途テンプレート | 削除 | 7種類のアイコン＋名称のみ |

既存の値を既定値で上書きする処理は加えず、位置と文言だけを変える。基本に残すのは形式・種類・期間・横軸・縦軸の5項目を基本とし、作品では時点、ヒストグラムでは区間数、テーブルでは列・写真を使う。いずれも6項目以内。

## 改訂後の計測結果

| 条件 | 文字数（前→後） | 削減率 | 常設項目（前→後） | 説明・補足（前→後） | 形式・データ・軸の収まり |
|---|---:|---:|---:|---:|---|
| PC 1440×800 | 814 → 100 | 87.7% | 13 → 5 | 20 → 0 | 軸の下端517.8px、スクロール領域の下端783px |
| モバイル390×844・展開 | 787 → 100 | 87.3% | 13 → 5 | 20 → 0 | 軸の下端790.5px、スクロール領域の下端843px |

同じ新規折れ線テンプレートで、同じDOM計測方法を使用した。7形式それぞれについても、PCとモバイルで基本項目6個以下・説明0個・ラベル8文字以下・閉じた要約20文字以下をブラウザーテストで確認した。改訂後の記録は `analytics-settings-density-after.json`。

基本項目の数はchart/sourceのラジオ群、期間セグメント、複数指標のチップ群をそれぞれ1項目として数える。単なるネイティブinputタグ数ではなく、利用者が設定する項目数である。期間の「指定」を選んだときの開始・終了や、利用者が自分で開いた「詳細」は段階的開示の対象として別扱い。
