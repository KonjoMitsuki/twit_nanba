SVG assets exported from the [Apple HIG design in Figma](https://www.figma.com/design/3o8LliiKzV1VU3RCnSs5fN?node-id=9-616).

- `brand.svg` (34×34), `profile.svg` (35×35): sidebar marks.
- `metric-*.svg` (29×29): monthly metric backgrounds.
- `post-dot.svg`, `highlight-dot.svg` (7×7): calendar post indicators.
- `toggle.svg` (23×23), `toggle-desktop.svg` (21×21): settings switch indicators.

Asset colors follow the calendar palette (ivory, charcoal, lime and coral); exported geometry is preserved.

Artwork imagery is supplied dynamically by the application data.
